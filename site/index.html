Screenshots at the speed of hjkl

Vishot is a keyboard-first, Vim-inspired screenshot tool for macOS. Pick a window, a single button, or a whole display, mark it up, and paste it without reaching for the mouse.

How it works

  1. ⇧⌘S opens the picker. From there it's hjkl, Tab and ↵. The mouse can stay where it is.

  2. hjkl or the arrow keys jump to the nearest window in that direction, across every screen.

  3. f puts a label on every button, message and pane. Type the label and it's selected. No dragging a box around it.

  4. ⇧↵ freezes the shot in place. a draws an arrow, r a box, t a label, c crops.

  5. y copies it, s saves a PNG to your screenshot folder, S does both.
